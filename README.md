# 🐋 울산고래여지도

> 김정호의 *대동여지도*가 조선을 걸어서 그렸다면,
> 울산고래여지도는 **고래의 시선**으로 울산을 그립니다.

울산을 구·군이 아니라 **고래 테마**로 다시 그린 테마 관광 큐레이션 웹 서비스입니다.
고지도(輿地圖) 톤의 인터랙티브 지도 위에서 울산의 고래 자원을 탐험하고,
동행·일정에 맞춘 코스를 추천받고, 현장 방문을 인증해 나만의 고래여권을 채웁니다.

**2026 관광데이터 활용 공모전** 웹·앱 개발 부문 출품작 · 팀 **울산큰고래**

🔗 **데모:** **https://ulsan-whale-yeojido.vercel.app**

---

## 왜 '고래 여지도'인가

관광 정보 서비스는 대개 **행정구역**으로 지역을 나눕니다. 중구·남구·동구·북구·울주군으로 나뉜 목록은
정확하지만, 여행자가 실제로 궁금해하는 "울산에서 무엇을 만날 수 있는가"에는 답하지 못합니다.

울산에는 다른 도시에 없는 자원이 있습니다. 전국 유일의 **고래문화특구**, 선사시대 고래잡이를 새긴
**반구대 암각화**, 국내 유일의 고래 관찰 크루즈 **고래바다여행선**. 이 서비스는 이것들을 하나의
이야기로 꿰어 **고래 테마 4분류**로 콘텐츠를 조직합니다.

| 차별점 | 내용 |
| --- | --- |
| 🗺️ **고래 테마 분류** | 행정구역이 아닌 고래 문화·관찰·유산·자연으로 콘텐츠를 조직 |
| 📜 **여지도 인터랙티브 지도** | 단순 리스트가 아닌 고지도 스타일 지도가 서비스의 본체 |
| 🌊 **시즌을 아는 추천** | 고래바다여행선 운항기·휴관일·축제 기간을 날짜 기준으로 반영 |
| 🛂 **고래여권** | GPS 현장 인증으로 스탬프를 모으는 방문 기록 |

### 고래 테마 4분류

| 테마 | 대표 자원 |
| --- | --- |
| 🏛️ **고래 문화** | 장생포 고래문화특구 — 박물관·생태체험관·문화마을 |
| 🌊 **고래 관찰** | 고래바다여행선 — 바다 위 고래의 시선 (4~11월) |
| 🪨 **고래 유산** | 반구대 암각화 — 선사시대 고래잡이의 기록 |
| 🏞️ **고래의 강·산** | 태화강·영남알프스 — 고래 도시를 품은 자연 |

## 주요 기능

### 🗺️ 여지도 — `/map`
고지도 톤으로 스타일링한 인터랙티브 지도. 고래 테마별 마커와 범례로 울산을 탐험하고,
마커를 누르면 그 장소에 '도착'하는 몰입 화면과 함께 상세 정보(이미지·운영시간·휴무·요금·전화)가 열립니다.
이름 검색, 현 위치 기반 주변 음식점·카페·숙박 연계도 지원합니다.

### 🧭 코스 추천 — `/recommend`
**동행 유형**(가족·연인·친구·혼자) × **체류 기간**(당일·1박2일·2박3일) × 관심사를 조합해
규칙 기반 엔진이 코스를 만듭니다. 단순 나열이 아니라 —

- 동행 유형별로 테마·카테고리 가중치가 달라 **결과가 실제로 갈립니다**
- 거리 기반 방문 순서 최적화 후 **시간표**(도착·체류·이동수단)를 세웁니다
- **휴관일·비운항기·축제 종료**를 날짜 기준으로 제외하고, 뺀 이유를 화면에 설명합니다
- 비운항기에는 상시 관람 가능한 **대체 스팟**을 제안합니다

### 🛂 고래여권 — `/passport`
관광지에 도착해 GPS로 방문을 인증하면 스탬프가 쌓이고, 모은 스탬프로 탐험가 등급이 올라갑니다.

### 🏠 랜딩 — `/`
여지도 컨셉 스토리텔링과 울산 대표 스팟 캐러셀로 서비스의 세계관을 먼저 전달합니다.

## 기술 스택

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 프레임워크 | **Next.js 15** (App Router) | 서버 라우트로 OpenAPI 프록시·캐싱을 한곳에 모으고 SSR로 관광 SEO 확보 |
| 언어 | **TypeScript** | 중첩·불규칙한 OpenAPI 응답을 파싱 경계에서 타입으로 검증 |
| 지도 | **MapLibre GL** | 고지도 비주얼을 위한 커스텀 스타일 자유도 |
| 상태·데이터 | **TanStack Query** | 캐시·재검증을 선언적으로 |
| 스타일 | **Tailwind CSS v4** | 여지도 디자인 토큰(한지·먹·인주·쪽빛)을 CSS 변수로 |
| 캐시 | **Upstash Redis** (인메모리 폴백) | 서버리스 환경에서 스냅샷·쿼터 공유 |
| 배포 | **Vercel** (+ Cron) | 일 1회 야간 배치로 데이터 갱신 |

데이터는 **공공데이터 관광 OpenAPI**를 사용합니다. 울산(areaCode=7) 전수 수집 → 정규화·중복 제거 →
고래 테마 태깅 → Redis 캐싱 → 일 1회 야간 배치 갱신 파이프라인으로 운영합니다.

## 빠른 시작

```bash
# 1) 의존성 설치
npm install

# 2) 환경 변수 준비
cp .env.example .env.local
#    → .env.local 을 열어 실제 값을 채웁니다 (아래 표 참고)

# 3) 개발 서버
npm run dev        # http://localhost:3000
```

API 키가 아직 없어도 괜찮습니다. `.env.local` 에서 `USE_MOCK_DATA=true` 로 두면
mock 픽스처로 전체 화면이 동작합니다.

```bash
npm run build      # 프로덕션 빌드
npm start          # 빌드 결과 실행
npm run collect    # 전수 수집 배치 수동 실행
```

### 환경 변수

| 변수 | 필수 | 설명 |
| --- | :---: | --- |
| `TOUR_API_SERVICE_KEY` | ● | 관광 OpenAPI 인증키. **서버에서만** 사용 |
| `TOUR_API_BASE_URL` | ● | 국문관광정보 서비스 베이스 URL |
| `TOUR_API_AREA_CODE` | ● | 울산 지역코드 (`7` 고정) |
| `USE_MOCK_DATA` | | `true` 면 키 없이 mock 픽스처로 동작 |
| `UPSTASH_REDIS_REST_URL` / `_TOKEN` | | 비우면 인메모리 캐시로 자동 폴백 |
| `CRON_SECRET` | ● | 배치·퍼지 엔드포인트 보호 토큰. **미설정 시 401로 차단**(fail-closed) |
| `ODSAY_API_KEY` | | 대중교통 경로 안내. 없으면 해당 기능만 조용히 꺼짐 |

> ⚠️ 비밀값은 `.env.local` 에만 두고 절대 커밋하지 않습니다. 저장소에는 `.env.example` 만 올라갑니다.
> `NEXT_PUBLIC_` 접두사를 붙이면 값이 클라이언트 번들에 그대로 실리므로 키에는 절대 사용하지 않습니다.

## 프로젝트 구조

프론트엔드와 백엔드를 **담당자별로 분리**했습니다. 실제 코드는 전부 `frontend/`·`backend/` 에 있고,
`app/` 에는 Next.js가 요구하는 얇은 라우팅 글루(re-export)만 둡니다.

```
frontend/              프론트엔드 (담당: 이숙빈)
  screens/             화면 본체 — Landing · Map · Recommend · Passport · NotFound
  components/
    home/              랜딩 히어로·스팟 캐러셀
    map/               여지도 지도 · 마커 · 범례 · 상세 패널 · 방문 인증
    ui/ chrome/        디자인 시스템
  lib/                 방문 기록 · 대중교통 조회 클라이언트
  globals.css          Tailwind v4 + 여지도 디자인 토큰

backend/               백엔드 / BFF (담당: 이윤석)
  routes/              API 핸들러 본체
  lib/
    tourapi.ts         관광 OpenAPI 클라이언트 — 인증키는 여기서만 사용
    collect.ts         전수 수집(페이지네이션)
    adapter.ts         원시 응답 → 도메인 모델 매핑 + 고래 테마 태깅
    recommend.ts       코스 추천 엔진 — 가중 점수 → 거리 순서화 → 시간표
    season.ts          시즌·제철·대체 스팟 (날짜 외부 주입 가능)
    operating.ts       운영시간·휴무 파서
    cache.ts           Redis 우선 + 인메모리 폴백
    mock/              mock 픽스처

app/                   Next.js 라우팅 글루만 (re-export)
  api/…/route.ts       → backend/routes/*
  */page.tsx           → frontend/screens/*
```

각 폴더의 `README.md` 에 담당·구성이 더 자세히 정리돼 있습니다 →
[frontend/README.md](frontend/README.md) · [backend/README.md](backend/README.md)

### 데이터 접근 규칙

모든 외부 API 호출은 **서버 BFF**(`app/api/` → `backend/routes/`)를 경유합니다.
프론트엔드는 `fetch("/api/…")` 로만 데이터에 접근하며, 인증키를 직접 다루지 않습니다.
외부 이미지도 `/api/img` 프록시를 거쳐 출처 도메인이 클라이언트에 노출되지 않게 합니다.

### API

| 엔드포인트 | 설명 |
| --- | --- |
| `GET /api/spots` | 지도용 스팟 목록 (`scope` · `theme` · `q` · `lang`) |
| `GET /api/spots/[id]` | 스팟 상세 — 운영시간·요금·갤러리 |
| `GET /api/recommend` | 코스 추천 (`companion` · `duration` · `interests` · `date`) |
| `GET /api/nearby` | 주변 음식점·카페·숙박 (`spotId` 또는 `lon`·`lat`) |
| `GET /api/transit` | 두 지점 사이 버스 경로 |
| `GET /api/img` | 외부 이미지 프록시 (허용 호스트만) |
| `GET /api/health` | 헬스체크 — 캐시·쿼터·배치 상태 |
| `POST /api/batch/collect` | 야간 수집 배치 · 토큰 필요 |
