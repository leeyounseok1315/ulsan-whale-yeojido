# 지도 라이브러리 라이선스 · 쿼터 검토 (W2)

> 내부 검토 문서. 사용자 노출 화면에는 공사 명칭 비노출, 출처는 '공공데이터' 중립 표기.

## 1. 지도 렌더링 방식 — 1차 선정: **커스텀 SVG 여지도 캔버스**

| 후보 | 장점 | 단점 | 라이선스/쿼터 |
|---|---|---|---|
| **커스텀 SVG (현재 채택)** | 고지도(여지도) 비주얼 자유도 최고, 외부 타일 의존 없음, 쿼터·과금 없음, 좌표 투영만 교체하면 데이터 레이어 유지 | 실측 지오데이터 아님(개념 지도), 직접 그려야 함 | 없음 (자체 자산) |
| MapLibre GL JS | 오픈소스, 세피아 커스텀 스타일 가능 | 타일 소스 별도 필요(스타일/타일 제공자 약관·쿼터 확인 필수) | MapLibre는 BSD, **타일 제공자(예: MapTiler/Stadia 등) 약관·일일 쿼터·attribution 표기 별도** |
| 카카오맵 SDK | 국내 POI 정확도·개발 속도 | 고지도 비주얼 제약, 로고/attribution 강제 | 카카오 약관·일일 호출 한도 준수 필요, 앱키 노출 관리 |

**결론:** W1~W6 핵심 차별점(여지도 비주얼) + 타일 라이선스/쿼터 리스크 회피를 위해 **커스텀 SVG 캔버스**를 채택. 마커/데이터 레이어는 렌더러와 분리(`projectToMap`)해, 추후 실측 지도(MapLibre/카카오)로 전환 시 투영 함수만 교체 가능.

**전환 시 체크리스트(추후):** 타일 제공자 약관·**필수 attribution 문구**·일일 쿼터·커스텀 타일 재배포 가능 여부·앱키 서버 보관.

## 2. 관광 OpenAPI 호출 쿼터 · 레이트리밋

- 일일 호출 한도는 `TOUR_API_DAILY_QUOTA`(기본 1000)로 추적 — `lib/metrics.ts`.
- 80% 도달 시 `warn`, 초과 시 추가 호출 차단(`canCall()`) 후 캐시/스냅샷 폴백.
- 수집은 페이지 호출 간 간격(120ms)·지수 백오프·타임아웃(8s)·재시도(3회)로 레이트리밋 배려 — `lib/tourapi.ts`, `lib/collect.ts`.
- 런타임 직접 호출 최소화: 30분 TTL 캐시(`spots:all:v1`) + 야간 배치(W3) 갱신.
- 현황은 `/api/health`의 `metrics`에서 내부 확인(공사 비노출).
